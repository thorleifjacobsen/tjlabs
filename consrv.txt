Build a multi-page demo website for Con-Serv AS, a Norwegian steel fabrication and construction company based in Grimstad. The site should feel professional, trustworthy, and industrial — clean white base with dark anthracite accents, so visitors immediately think "this is the company we have been looking for."

---

## PROJECT SETUP

- Framework: Next.js App Router, TypeScript
- All files under: src/app/demo/con-serv/
- Tailwind CSS available globally, no setup needed
- Standalone layout.tsx — no shared components from outside src/app/demo/con-serv/
- No imports from outside src/app/demo/con-serv/
- Use <img> tags, NOT Next.js Image component
- export const metadata = { robots: 'noindex' } on ALL page.tsx files
- Mobile-first, fully responsive
- No em dashes or en dashes anywhere in code or text
- No Inter font
- Use correct Norwegian letters: Æ, Ø, Å wherever applicable
- Font: Import "Barlow Condensed" (weights 600, 700) and "Barlow" (400, 500) from Google Fonts via a <link> tag in layout.tsx. Use Barlow Condensed for all headings, Barlow for body text.

## GENERAL RULES FOR ALL PAGES

- Use correct Norwegian: Æ, Ø, Å in all text
- No em dashes anywhere — use comma or period instead
- No en dashes anywhere — use "til" or "og" instead
- No placeholder Lorem Ipsum text — all text should be real Norwegian content based on the info above
- All pages must have the anthracite CTA banner near the bottom before the footer (except kontakt page which already ends with contact info)
- All internal links use href="/demo/con-serv/[page]"
- Section headings in Barlow Condensed uppercase
- Keep the nav active state: highlight the current page link in accent color (use usePathname from next/navigation in layout.tsx — mark layout as "use client")
- The overall feel: industrial but approachable, premium but not pretentious. A family-run Norwegian steel company that knows what they are doing.
